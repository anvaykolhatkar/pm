This folder contains start/stop scripts for local Docker-based development.

Current scripts:

- `start-linux.sh`, `stop-linux.sh`
- `start-mac.sh`, `stop-mac.sh`
- `start-windows.ps1`, `stop-windows.ps1`
- `start-windows.bat`, `stop-windows.bat`

All scripts target the root `docker-compose.yml` and manage the same `pm-app` container.
